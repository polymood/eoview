Download eoview

Install it once. After that, eoview keeps itself up to date.

Windows

Download the installer

The installer puts eoview in your own user folder, so you don't need administrator rights. It adds eoview to the Start menu, and project files open in eoview when you double-click them.

The installer isn't signed by a certificate yet, so Windows may show "Windows protected your PC". Click More info, then Run anyway.

Prefer no installer? Download the program on its own and put it in a folder you can write to, so that it can update itself.

Linux and macOS

Open a terminal, paste this line and press Enter. It installs eoview for your user only. On Linux it also adds eoview to your applications menu.

curl -fsSL https://github.com/polymood/eoview/releases/latest/download/install.sh | sh

What you need

Windows
Windows 10 or 11, 64-bit.
Linux
A 64-bit PC with a recent distribution, for example Ubuntu 22.04 or newer.
macOS
A Mac with Apple silicon (M1 or newer).
Processor
On a PC, a processor from about 2015 or newer.
Graphics
Any recent graphics card. The one built into your processor is enough.

Updates

Each time eoview starts, it checks GitHub for a new version. If there is one, it downloads it in the background, and you get the new version the next time you start eoview.

Every update is signed, and eoview checks the signature before it installs anything. You can turn updates off in Preferences, under General. Older versions are on the releases page.
