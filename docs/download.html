Download eoview

Install eoview one time. After that, eoview updates itself.

Windows

Download the installer

The installer puts eoview in your user folder (%LOCALAPPDATA%\Programs\eoview). It does not need administrator rights. It adds eoview to the Start menu, and opens workspace files (.eoview) in eoview.

The installer has no Windows code signature yet. Thus Windows SmartScreen can show the message “Windows protected your PC”. To continue, select More info, then Run anyway.

Without the installer: eoview-windows-x86_64.exe. Put it in a folder that you can write to, so that it can update itself.

Linux and macOS

Run this command in a terminal. It puts eoview in ~/.local/bin. On Linux, it also adds eoview to the menu of applications.

curl -fsSL https://github.com/polymood/eoview/releases/latest/download/install.sh | sh

Then start eoview from the menu, or with the command eoview.

Requirements

Windows
Windows 10 or 11, 64-bit.
Linux
x86_64, glibc 2.35 or newer (for example Ubuntu 22.04 or newer).
macOS
Apple silicon (M1 or newer).
Processor
On x86_64, a processor with AVX2 (most processors since 2015).
Graphics
A GPU with Direct3D 12, Vulkan or Metal. An integrated GPU is sufficient.

Updates

At each start, eoview reads the version of the latest release on GitHub. If that version is newer, eoview downloads it in the background and checks its signature. Then eoview replaces its program file. The new version runs at the next start.

To stop the automatic updates, open Preferences, then General, and clear Automatic updates. All versions are on the releases page.

Verify a download

Each file of a release has a signature file (.sig, Ed25519). eoview installs an update only if the signature is correct for this public key:

-----BEGIN PUBLIC KEY-----
MCowBQYDK2VwAyEA8r+3vit0GYl7rQyR/86Ptl9uazFc9di66jCroG0AKvc=
-----END PUBLIC KEY-----

To verify a file yourself, save the key as eoview.pub, then use OpenSSL 3:

openssl pkeyutl -verify -pubin -inkey eoview.pub -rawin -in eoview-linux-x86_64 -sigfile eoview-linux-x86_64.sig
