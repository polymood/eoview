Privacy policy

eoview collects no personal data. It has no telemetry, no analytics and no user accounts.

Last change: 9 October 2026.

Connections that eoview makes

The check for updates

At each start, eoview downloads a small file from github.com to read the version of the latest release. If the version is newer, eoview downloads the new program from github.com. GitHub receives your IP address and the version of eoview, as for each download. The GitHub privacy statement applies to these requests.

To stop the check, open Preferences, then General, and clear Automatic updates. Then eoview makes no connection that you did not request.

The data that you open

When you open a URL (HTTP, HTTPS or S3), eoview reads the data from that server. That server receives your IP address and the requests. The S3 credentials come from your AWS configuration. They stay on your computer, and eoview sends them only to the server of the bucket.

Python scripts

eoview runs the Python scripts and notebooks that you open, on your computer. A script can make its own connections. eoview does not control them.

Data on your computer

eoview keeps these files on your computer only:

  • The preferences and the list of recent products and workspaces: %APPDATA%\eoview on Windows, ~/.config/eoview on Linux and macOS.
  • The disk cache of remote data: %LOCALAPPDATA%\eoview\remote on Windows, ~/.cache/eoview/remote on Linux, ~/Library/Caches/eoview/remote on macOS. You can change its size or its location in the preferences.
  • The workspace files, figures, exports and videos that you save.

This website

GitHub Pages hosts this website. The website sets no cookies and loads nothing from other servers. GitHub can record the IP addresses of the visitors, as its privacy statement tells.
