Privacy policy

eoview doesn't collect any personal data. There is no tracking, no analytics and no account.

Last updated: 9 October 2026.

When eoview goes online

Checking for updates

Each time it starts, eoview asks GitHub whether there is a newer version, and downloads it if there is. Like any download, GitHub sees your IP address and which version of eoview you have. These requests fall under the GitHub privacy statement.

You can turn this off in Preferences, under General. After that, eoview only goes online when you ask it to.

Files you open from the internet

When you open a file from a web address or a cloud bucket, eoview downloads it from that server, which sees your IP address. If you use cloud storage keys, they stay on your computer and are only sent to the storage service they belong to.

Your Python scripts

eoview runs the scripts and notebooks you open on your own computer. What a script does online is up to the script, not eoview.

What eoview keeps on your computer

  • Your settings and the list of recent files: %APPDATA%\eoview on Windows, ~/.config/eoview on Linux and macOS.
  • A cache of data downloaded from the internet: %LOCALAPPDATA%\eoview\remote on Windows, ~/.cache/eoview/remote on Linux and ~/Library/Caches/eoview/remote on macOS. You can change its size and location in the preferences.
  • The projects, figures, exports and videos that you save.

This website
